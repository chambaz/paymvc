# Brand marks

The landing page uses monochrome marks as CSS masks, so they follow the neutral light/dark theme. The network names provide their accessible labels.

- Network SVGs: [Web3Icons](https://github.com/0xa3k5/web3icons), revision `fcd2737648c6feafd7de16566360637e737e4776`, from `packages/core/src/svgs/networks/mono/`.
- Thruput uses the Stellar mark, as on the [official Project Thruput site](https://www.thruput.network/).
- GitHub mark: [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/github.svg), distributed under CC0. GitHub and network marks remain trademarks of their owners.
